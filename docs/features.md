# KRVT Features

## Reader

Owns the reading experience: chapter navigation, reader settings, reading progress, bookmark actions in the reader surface, scroll restoration, and reader keyboard behavior.

## Library

Owns the user's saved novel collection, library search/filter/sort behavior, library history views, and library-level novel actions.

## Import

Owns importing novel content from supported sources and adding imported novels to the library.

## Update

Owns checking and applying updates for saved novels.

## Backup

Owns library export/import backup workflows.

## TTS

Owns text-to-speech playback, voices, TTS runtime state, and TTS persistence.

## Settings

Owns app-level settings exports and bridges reader settings through the reader feature's public architecture.
